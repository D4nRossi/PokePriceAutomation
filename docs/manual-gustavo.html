01Em 1 minuto

Os produtos da coleção Celebração 30 Anos esgotam em minutos. Em 23/09 o Blister Duplo voltou ao estoque da Copag às 18:01 e sumiu às 18:03. Ninguém consegue ficar atualizando a página o dia inteiro, então um programa faz isso por nós.

A cada 5 minutos ele pergunta à loja da Copag se algum dos 8 produtos voltou. Se voltou, manda uma mensagem no grupo do Telegram Gugu Automation Master Ultra com o preço e o link. Tudo o que ele vê fica guardado num banco de dados local, e é daí que sai o histórico de preços.

A segunda parte, que é com você, é o Mercado Livre: avisar quando alguém anunciar um desses produtos pelo preço oficial ou mais barato. Ela está desligada porque o Mercado Livre só libera essas informações para quem tem um aplicativo cadastrado. O primeiro passo é criar esse cadastro na sua conta.

02Como as peças se ligam

São quatro peças. Três já funcionam, e a quarta (tracejada) é a que você vai destravar.

Tudo isso roda no computador de quem liga o monitor. Não existe servidor na nuvem e não há custo.

E se houver mais de um computador?

Você pode rodar uma cópia na sua máquina. Para o grupo não receber o mesmo alerta duas vezes, só um computador envia de cada vez: o líder (hoje, o do Daniel). Os outros são reservas: vigiam em silêncio e só começam a enviar se o líder ficar 15 minutos sem dar sinal de vida, por exemplo porque o PC dele desligou.

Para saber o que já foi avisado, os computadores usam uma mensagem fixada no grupo, escrita pelo próprio bot. É aquele texto cheio de chaves {"a":...} que aparece no topo do grupo. Parece lixo, mas é a memória compartilhada do sistema.

Não mexa

Não apague, não edite e não desafixe a mensagem "🤖 Estado do monitor". Se ela sumir, o bot cria outra, mas pode repetir um alerta de cada produto.

03Glossário

Os termos que aparecem neste manual, cada um numa frase.

API
Uma "porta de serviço" de um site, feita para programas conversarem com ele sem abrir a página. Em vez de HTML, ela responde com dados organizados.
Docker
Um programa que roda outros programas dentro de "caixas" isoladas. Você instala o Docker Desktop e não precisa instalar Python, banco de dados nem mais nada.
Container
Cada uma dessas caixas. Aqui são duas: monitor (o programa) e db (o banco de dados).
docker compose
O comando que liga ou desliga as duas caixas de uma vez, lendo a receita do arquivo compose.yaml.
.env
Um arquivo de texto com as configurações e senhas daquela máquina. Ele nunca vai para o GitHub.
Token
Uma senha comprida que um programa usa para provar quem é. O bot do Telegram tem um, e o Mercado Livre vai gerar outro.
App do Mercado Livre
Um cadastro de desenvolvedor na sua conta do ML. Ele gera o App ID (nome de usuário do programa) e a Secret Key (senha do programa).
OAuth
O processo em que você autoriza, pelo navegador, um programa a usar a sua conta. É o mesmo "Entrar com Google" que você já conhece.
Redirect URI
O endereço para onde o ML manda você depois de autorizar. Aqui ele só precisa existir: usamos a página do projeto no GitHub.
HTTP 200 / 401 / 403
Códigos de resposta de um site. 200 é "ok, aqui está". 401 é "quem é você?". 403 é "sei quem você é, mas não pode".
SKU
O código interno de um produto na loja. O Box ex Greninja, por exemplo, é o SKU 2608 na Copag.
Produto de catálogo /p/MLB…
A página "oficial" de um produto no ML, que junta todos os vendedores daquele item. Comparar dentro dela evita confundir o produto com carta avulsa ou importado.
Teto
O preço máximo que dispara o alerta do ML: preço sugerido + R$ 1,00.
Líder e reserva
O computador que envia os alertas e os que ficam de prontidão. Veja a seção 02.
Monitor cego
Quando uma loja para de responder 3 vezes seguidas. O grupo é avisado, porque um monitor que para em silêncio é pior que nenhum.

05Criar o app do Mercado Livre

O app fica na sua conta porque o cadastro pede o seu login e o aceite dos termos de desenvolvedor. Ninguém pode fazer isso por você.

  1. Abra developers.mercadolivre.com.br e entre com a sua conta normal do Mercado Livre.

  2. Procure Criar aplicação, que fica no painel de aplicações (às vezes chamado de DevCenter). Se o site pedir para aceitar os termos de desenvolvedor, leia e aceite.

  3. Preencha o formulário assim:

    NomePokePriceAutomation (se já existir, qualquer variação) Nome curtopokeprice DescriçãoMonitor pessoal de preço de produtos Pokémon TCG Redirect URIhttps://github.com/D4nRossi/PokePriceAutomation PermissõesSó leitura. Se aparecer offline_access, marque também. Notificações / tópicosNenhum. Deixe em branco.

    Não precisa de logo nem de site próprio.

  4. Salve. O ML vai mostrar dois valores. Anote os dois:

    App IDum número comprido, tipo 1234567890123456. Pode ser visto por outros sem problema. Secret Keyuma sequência de letras e números. É uma senha: trate como tal.
Se mudou

Sites mudam de visual. Se algum nome de botão ou campo não bater com este manual, siga pelo sentido. O que importa é sair com o App ID e a Secret Key, com permissão só de leitura e a Redirect URI acima.

Por que só leitura

O monitor só consulta preço. Ele nunca compra, nunca coloca no carrinho e nunca mexe na sua conta. Dar só leitura garante isso mesmo se a chave vazar.

06Guardar e entregar as chaves

O projeto está num repositório público do GitHub. Qualquer pessoa na internet lê o que estiver lá. Por isso as chaves moram só num arquivo chamado .env, no computador que roda o monitor. Esse arquivo é ignorado pelo GitHub de propósito.

OndePode colocar a Secret Key?
Grupo do Telegramnão todo mundo do grupo vê, e fica salvo
Print de tela, e-mail, issue ou commitnão
Mensagem direta para o Daniel, apagada depoisaceitável
Gerenciador de senha compartilhado (Bitwarden, 1Password)melhor opção
Arquivo .env da sua máquina, se você mesmo rodarsim

No .env as linhas ficam assim, com os valores no lugar dos colchetes:

ML_CLIENT_ID=[App ID]
ML_CLIENT_SECRET=[Secret Key]
Vazou?

Sem pânico. No painel do app no Mercado Livre dá para gerar uma Secret Key nova. A antiga para de funcionar na hora, e é só atualizar o .env.

07O que acontece depois

Cada passo só começa se o anterior der certo. Nada é feito no chute.

passo 1

Teste de acesso. Com as chaves, o Daniel refaz as consultas que hoje dão erro 401/403 e anota o resultado de cada uma.

passo 2

Autorização, se precisar. Talvez o ML exija que o dono do app autorize pelo navegador. Aí o Daniel te manda um link que começa com https://auth.mercadolivre.com.br/authorization?.... Você abre logado, clica em autorizar, cai numa página do GitHub e copia o endereço completo da barra do navegador para ele. O código vale poucos minutos, então faça isso na hora.

passo 3

Programar a leitura. Só depois de ver uma resposta real do ML o programa aprende a ler preço, vendedor e condição.

passo 4

Filtrar o produto certo. Só contam ofertas da página de catálogo, produto novo e nacional. Carta avulsa, lote, importado e "compatível" ficam de fora.

passo 5

Ligar. O ML entra no mesmo grupo e com o mesmo formato de mensagem da Copag.

plano B

Se o ML continuar bloqueando mesmo com o app, a parte do ML sai do projeto e o grupo segue só com a Copag. Não vamos raspar o site na marra: viola os termos do ML e bloqueia o IP.

Sem garantia

O erro de hoje vem de uma regra de política do ML, não só da falta de login. É possível que o app não resolva. O passo 1 existe para descobrir isso rápido.

09Rodar na sua máquina

É opcional, mas deixa o sistema mais robusto: se o PC do Daniel desligar, o seu assume sozinho em 15 minutos. O seu computador precisa ser Windows 10/11, Mac ou Linux, com uns 2 GB livres.

  1. Instale o Docker Desktop em docker.com/products/docker-desktop. No Windows ele pode pedir para reiniciar e instalar o WSL, aceite. Abra o Docker Desktop e espere o ícone da baleia ficar parado (verde, "Engine running").

    Nas configurações do Docker Desktop, ligue "Start Docker Desktop when you sign in". Assim o monitor volta sozinho quando o PC reinicia.

  2. Baixe o projeto. Abra github.com/D4nRossi/PokePriceAutomation, clique no botão verde Code e depois em Download ZIP. Extraia numa pasta fácil, por exemplo C:\PokePrice.

  3. Crie o seu .env. Na pasta, copie o arquivo .env.example e renomeie a cópia para .env. Abra no Bloco de Notas e preencha só estas linhas:

    TELEGRAM_BOT_TOKEN=[peça ao Daniel, em privado]
TELEGRAM_CHAT_ID=[peça ao Daniel]
LIDER=false
MAQUINA=gustavo
    Importante

    LIDER tem que ser false. Se duas máquinas forem líder, o grupo recebe todos os alertas em dobro.

    No Windows, se o arquivo virar .env.txt, ative "Extensões de nomes de arquivos" no menu Exibir do Explorer e apague o .txt.

  4. Ligue. Na pasta do projeto, clique na barra de endereço do Explorer, digite powershell e aperte Enter. Na janela azul, cole:

    docker compose up -d --build

    Na primeira vez demora uns 2 minutos, porque baixa tudo. Nas próximas é instantâneo.

  5. Confira. Cole este comando. Todas as linhas precisam começar com [ok] ou [..]:

    docker compose run --rm monitor python -m monitor.main --verificar

    O resultado esperado é parecido com este:

    [ok] banco: 0 observações gravadas
[..] máquina: gustavo · líder: False · failover: 15 min
[ok] bot: @GuguLindo_bot
[ok] grupo: Gugu Automation Master Ultra (supergroup)
[ok] bot é administrator, pode fixar: True
[..] estado compartilhado: mensagem 6, último ativo DESKTOP-VPRVBHA em ...

12Perguntas frequentes

O bot pode comprar alguma coisa ou mexer na minha conta do ML?

Não. Ele só lê preço e estoque. Não faz login na conta de compras, não adiciona ao carrinho e não compra. O app do ML é criado com permissão só de leitura justamente para garantir isso.

Por que não checa a cada minuto, se esgota tão rápido?

Por educação com as lojas: consulta demais parece ataque e faz o IP ser bloqueado. Um monitor bloqueado fica cego justamente no dia que importa. Cinco minutos é o mínimo, e o programa ignora valores menores.

Custa alguma coisa?

Não. Roda no seu computador, o Docker Desktop é gratuito para uso pessoal, e o Telegram e o app do ML também não custam nada.

Meu PC precisa ficar ligado o tempo todo?

Só se você quiser ser reserva ativa. Se o seu PC estiver desligado, nada quebra: o do Daniel continua como líder.

O que é aquela mensagem cheia de código fixada no grupo?

É a memória compartilhada entre as máquinas: o que já foi avisado e qual máquina está enviando. O bot edita essa mensagem a cada 5 minutos, sem notificar ninguém. Não apague.

Posso editar a lista de produtos?

Sim, no arquivo catalogo.json, que é texto puro. Depois rode docker compose restart monitor. Se tiver dúvida sobre o formato, mande para o Daniel antes.

E se eu quiser parar de participar?

Rode docker compose down na sua máquina e, se quiser, apague o app no painel de desenvolvedor do ML. O resto continua funcionando com a Copag.
